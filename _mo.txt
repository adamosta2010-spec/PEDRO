Asking to simulate a second thing was answered as a question about the first

The branch for "something is already showing in the ball" came before the branch
for "asked to build something", and the holding pattern puts something in the
ball the instant you ask - so the first request built, and every one after it
was heard as a question about what was already there. Which is exactly what it
looked like: you asked it to simulate an engine and it told you what an engine is.

A request to build now wins, and a question that is not one still goes to the
thing on screen.

  simulate an engine            -> builds it
  model the solar system        -> builds it
  what is that bit              -> asks about what is showing
  stop                          -> stops
